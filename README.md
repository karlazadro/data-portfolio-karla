# Data Portfolio — Karla Zadro

This repository contains a small selection of focused data/BI projects.  
Each project includes a short problem statement, the approach (cleaning/analysis), and a clear output (charts/dashboard + key insights).

## Projects

1) **AI Digital Readiness Dashboard**  
   A dashboard-style project that explores readiness indicators and summarises key patterns for quick decision-making.  
   Folder: `ai_digital_readiness_dashboard/`

2) **Youth NEET in Europe**  
   Analysis of youth NEET indicators across European countries/years, with comparisons and trends.  
   Folder: `project-1-youth-neet-europe/`

3) **Young Housing Overburden in the EU**  
   Analysis of housing cost overburden indicators for young populations, with cross-country comparisons and trends.  
   Folder: `project-2-young-housing-overburden-eu/`

## Tools
